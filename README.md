# Oper & Ballett Berlin – Kalender-Abo

Sammelt die regulären Aufführungen von Komischer Oper, Staatsoper Unter den Linden, Deutscher Oper und Staatsballett in einem abonnierbaren Kalender. Ein GitHub-Roboter aktualisiert ihn monatlich (oder auf Knopfdruck).

- **Kalender-Abo:** Link auf der Seite deiner GitHub Pages (`https://DEIN-NAME.github.io/opera-kalender/`).
- **Alle Produktionen im Überblick:** `PRUEFLISTE.md`
- **Produktion abwählen:** Titel in `gesehen.txt` eintragen. Künftige Termine verschwinden, vergangene bleiben.
- **Sofort aktualisieren:** Reiter „Actions“ → „Kalender aktualisieren“ → „Run workflow“.

Nicht enthalten: Führungen, Einführungen, Workshops, Konzerte, Kinder- und Familienstücke (Familienvorstellungen regulärer Produktionen wie dem Nussknacker bleiben).

Zum Spielzeitbeginn lohnt ein Blick in `PRUEFLISTE.md`; neue Produktionen sind dort mit **neu** markiert.
